_Written on 6 November 2026. Pricing and versions: official pages read that day, to be checked before you decide._

## My starting point

I tried it several months after ChatGPT, around 2025.

## What it does well

- **Long texts and documents**: rewrite, summarize, proofread a procedure.
- **Code**: write, explain and fix a script; the official page also presents Claude Code, a programming tool, in the paid plans.
- **Structured work**: the official page mentions projects, connectors, file creation and code execution depending on the plan.

## Where I stay wary

- Like every assistant, it can **make things up**, an option or a reference: check the documentation.
- **Usage limits depend on the plan** and reset by periods: heavy use hits the ceiling sooner on the free plan.
- It does not see your estate: an answer about "your" Active Directory rests on what you describe to it.

Where I find it better than the other assistants: development.

## IT use cases

| Need          | What I ask it                                      | What I check                         |
| ------------- | -------------------------------------------------- | ------------------------------------ |
| Script        | A commented script with error handling and logging | Each cmdlet, a run on a test account |
| Documentation | Clean up a procedure from rough notes              | The commands and the values          |
| Review        | Read an existing script and flag the risks         | The remarks, one by one              |
| Log analysis  | Spot a pattern in an anonymized excerpt            | The pattern in the full log          |

## Privacy and GDPR

- **Do not paste** secrets, personal data, message contents or internal diagrams into an individual plan.
- **Anonymize** before pasting.
- The **Enterprise** plan adds, according to the official page, administration controls, audit logs, configurable data retention and SCIM; the **Team** plan adds central billing, single sign-on and administration controls. Those are the plans to look at for business use, after reading the terms on data use.

## Pricing and versions (official page read on 6 November 2026)

| Plan       | Price shown                                                                 | What the page says                                        |
| ---------- | --------------------------------------------------------------------------- | --------------------------------------------------------- |
| Free       | $0                                                                          | Limited usage, no Claude Code                             |
| Pro        | $20 a month, or $17 a month billed annually ($200 upfront)                  | More usage than Free, Claude Code, projects, integrations |
| Max        | $100 a month                                                                | 5 times Pro usage, $100 a month in API credits            |
| Ultra      | $200 a month                                                                | 10 times Pro usage per week, $200 a month in API credits  |
| Team       | $20 per seat per month (annual) or $25 (monthly); Premium seat $100 or $125 | 2 to 150 members, central administration                  |
| Enterprise | $20 per seat per month (annual, 20 seats minimum) plus usage at API rates   | Administration, audit, custom retention                   |

Prices in dollars as displayed (the page does not state the tax treatment): check it before you decide.

## How I use it

I use the Pro plan professionally and the free plan personally. I use it daily, notably with Claude Code for development.

## What to do

1. Try the free plan on a real, anonymized case.
2. For code, ask it to explain what it proposes, then check the documentation.
3. For a team, compare Team and Enterprise on the contract, not on price.
4. Write down the date of your decision: plans change.
