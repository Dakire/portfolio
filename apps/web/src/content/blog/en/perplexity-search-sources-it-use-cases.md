## My starting point

I started searching with Perplexity in 2025.

## What it does well

- **A search with links to sources**: to find documentation, a security advisory or a recent fix, you start from an answer and trace back to the pages.
- **Saving time on a first read**: a summary of several pages, to be confirmed.

## Where I stay wary

- **The answer is not the source.** A summary can distort what the cited page says: open the link before relying on it, especially for a CVE, an end-of-support date or a command.
- **A cited source can be a bad one**: a forum, a blog with no authority. Prefer the vendor's documentation, CERT-FR, the CNIL.
- For dated information (price, version), look at the date of the cited source.

## IT use cases

| Need              | What I ask it                           | What I check                       |
| ----------------- | --------------------------------------- | ---------------------------------- |
| Security advisory | "Which versions are fixed for CVE-…?"   | The vendor's or CERT-FR's advisory |
| Documentation     | Find the official page for an option    | The page, not the summary          |
| Monitoring        | What is new in a product over the month | The dates of the sources           |

## Privacy and GDPR

- It is a **search**: what you type is sent to a third-party service. **Do not type** client names, personal data or internal information.
- Phrase **generic** questions ("how to configure X"), not "company Y's server has problem Z".

## How I use it

I use the free plan.

## What to do

1. Use it as a search engine that summarizes, not as a final answer.
2. **Always open the source** for information that commits you (security, date, price).
3. Type no internal data.
4. Check the price on the site before paying: the page shows prices billed annually.
