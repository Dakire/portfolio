_Written on 6 November 2026. Pricing and versions: official pages read that day, to be checked before you decide._

## My starting point

I used it for quick development, scripting, and it was fine. In my choice to try it, sovereignty was what counted.

## The name: Le Chat or Vibe?

Mistral's pricing page now presents its plans under the name **Vibe** and mentions "Le Chat" only in a note for students, without explaining the link between the two. The change is recent, from May 2026 (secondary sources give the same date, 28 May); **I could not verify it on an official source**. In this article, "Mistral" means the provider's consumer product, under either name.

## What it does well

- **A European provider**: relevant if you care where the provider is based (this does not replace reading the terms on data).
- **General use** and development: the page mentions writing code on the command line, in an editor or on the web, generating spreadsheets and slides, and a hundred or so connectors.
- **Readable prices** and a free plan.

## Where I stay wary

- **The product name** is in transition: update your notes and internal guidelines once it settles.
- The page shows **an inconsistency** on the student plan (amount of API credits, price): check before relying on it.
- Like the others, it can be wrong.

## IT use cases

| Need          | What I ask it                               | What I check                       |
| ------------- | ------------------------------------------- | ---------------------------------- |
| Script        | A commented Bash or Python script           | A run on a test machine            |
| Documentation | A procedure written up from notes           | The values and the names           |
| Explanation   | Explain an anonymized network configuration | Against the hardware documentation |

## Privacy and GDPR

- **Do not paste** personal data or secrets into the consumer plan.
- For professional use, **look at the Team plan** (verified domain, data export, per-user storage according to the page) and read the terms: the page does not detail single sign-on or audit logs for this plan, which secondary sources place under Enterprise.
- Being a French provider exempts you neither from anonymizing nor from reviewing the contract.

## Pricing and versions (official page read on 6 November 2026, excluding taxes)

| Plan | Price                     | What the page says                                          |
| ---- | ------------------------- | ----------------------------------------------------------- |
| Free | free (no price shown)     | Limited messages and searches, basic image generation       |
| Pro  | $14.99 per month          | More usage, all-day development, $15 a month in API credits |
| Team | $24.99 per user per month | Higher limits, 30 GB per user, domain verification          |

The page also shows "$50 a month" next to the Team plan's user count without explaining it: ask the provider to confirm before you buy.

## How I use it

I use the free plan.

## What to do

1. Try the free plan on an anonymized case, next to your usual tool.
2. If you choose Mistral for where it is based, **check the contract**, not just the country.
3. Write down the date: the name and the plans are changing.
