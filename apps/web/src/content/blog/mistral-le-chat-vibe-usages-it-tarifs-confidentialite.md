## Mon point de départ

Je l'ai utilisé pour du développement rapide, du scripting, et c'était correct. Dans mon choix de l'essayer, c'est la souveraineté qui a compté.

## Le nom : Le Chat ou Vibe ?

La page tarifaire de Mistral présente aujourd'hui ses offres sous le nom **Vibe** et ne mentionne « Le Chat » que dans une note pour les étudiants, sans expliquer le lien entre les deux. Le changement est récent, de mai 2026 (c'est aussi la date que donnent des sources secondaires, le 28 mai) ; **je n'ai pas pu le vérifier sur une source officielle**. Dans cet article, « Mistral » désigne le produit grand public de l'éditeur, sous l'un ou l'autre nom.

## Ce qu'il fait bien

- **Un éditeur européen** : pertinent pour qui se pose la question de la localisation de l'éditeur (cela ne remplace pas la lecture des conditions sur les données).
- **Un usage généraliste** et du développement : la page cite l'écriture de code en ligne de commande, dans un éditeur ou sur le web, la génération de tableaux et de présentations, et une centaine de connecteurs.
- **Des prix lisibles** et une offre gratuite.

## Où je me méfie

- **Le nom du produit** est en transition : mettez à jour vos notes et vos consignes internes quand il se stabilise.
- La page présente **une incohérence** sur l'offre étudiante (montant des crédits d'API, prix) : vérifiez avant de vous y fier.
- Comme les autres, il peut se tromper.

## Cas d'usage IT

| Besoin        | Ce que je lui demande                               | Ce que je vérifie                 |
| ------------- | --------------------------------------------------- | --------------------------------- |
| Script        | Un script Bash ou Python commenté                   | Un essai sur une machine de test  |
| Documentation | Une procédure rédigée en français à partir de notes | Les valeurs et les noms           |
| Explication   | Expliquer une configuration réseau anonymisée       | Avec la documentation du matériel |

## Confidentialité et RGPD

- **Ne collez pas** de données personnelles ni de secrets dans l'offre grand public.
- Pour un usage professionnel, **regardez l'offre Team** (domaine vérifié, export des données, stockage par utilisateur selon la page) et lisez les conditions : la page ne détaille ni l'authentification unique ni les journaux d'audit pour cette offre, que des sources secondaires placent chez Enterprise.
- Être un éditeur français ne dispense ni de l'anonymisation ni de l'analyse du contrat.

## Tarifs et versions (page officielle consultée le 6 novembre 2026, hors taxes)

| Offre | Prix                                | Ce que la page indique                                                       |
| ----- | ----------------------------------- | ---------------------------------------------------------------------------- |
| Free  | gratuit (aucun prix affiché)        | Messages et recherches limités, génération d'images simple                   |

## Mon usage

J'utilise l'offre gratuite.

## Que faire ?

1. Essayez l'offre gratuite sur un cas anonymisé, à côté de votre outil habituel.
2. Si vous choisissez Mistral pour la localisation, **vérifiez le contrat**, pas seulement le pays.
3. Notez la date : le nom et les offres évoluent.
