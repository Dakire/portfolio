_Article rédigé le 6 novembre 2026. Tarifs et versions : pages officielles consultées ce jour-là, à vérifier avant de décider._

## Mon point de départ

J'ai testé Copilot sur un PC compatible.

## Ce qu'il fait bien

- **Travailler dans les applications** : la page de Microsoft cite Word, Excel, PowerPoint, Outlook et Teams.
- **S'appuyer sur les données de l'organisation** : les résultats reposent sur ce que l'utilisateur a le droit de voir.
- **Un point d'entrée sans surcoût** : Copilot Chat est proposé sans coût supplémentaire avec des abonnements Microsoft 365 éligibles, en se connectant avec un compte professionnel.

## Où je me méfie

- **Il révèle les mauvais droits.** Si un dossier SharePoint est ouvert à tout le monde par erreur, Copilot le trouvera pour tout le monde. Faites le ménage des partages **avant** le déploiement.
- **Le coût s'ajoute** à la licence Microsoft 365, et certaines fonctions avancées sont facturées à l'usage en plus.
- Comme les autres, il peut se tromper : un résumé de réunion ou de document se relit.

Je n'ai pas vu Copilot faire remonter un document mal partagé, et je ne l'ai déployé chez aucun client : mon retour s'arrête à un essai personnel.

## Cas d'usage IT

| Besoin        | Ce que je lui demande                                             | Ce que je vérifie                              |
| ------------- | ----------------------------------------------------------------- | ---------------------------------------------- |
| Messagerie    | Résumer un long fil dans Outlook                                  | Les décisions et les dates                     |
| Documentation | Mettre en forme une procédure dans Word                           | Que rien n'a été inventé                       |
| Tableaux      | Une formule Excel à partir d'une description                      | Le résultat sur un échantillon                 |
| Sécurité      | Aucune confiance aveugle : il ne remplace pas un audit des droits | Les partages, avec les outils d'administration |

## Confidentialité et RGPD

- La page de Microsoft présente Copilot Business avec une **protection des données et une gouvernance de niveau entreprise** : lisez les conditions et la documentation du tenant avant le déploiement.
- **Auditez les droits** (SharePoint, OneDrive, Teams, boîtes partagées) avant d'activer la licence : voir [Sécuriser Microsoft 365 et Google Workspace](/blog/securiser-microsoft-365-google-workspace-reglages-de-base/).
- Informez les personnes concernées de ce qui est traité et par qui ; consultez votre référent RGPD pour l'analyse d'impact si le périmètre est large.

## Mon usage

Je ne paierais pas la licence, ni pour moi ni pour un client : je la trouve trop limitée.

## Que faire ?

1. **Commencez par les droits**, pas par les licences : un audit de partage d'une demi-journée évite les mauvaises surprises.
2. Testez Copilot Chat avec un petit groupe, sans licence supplémentaire.
3. Ne payez la licence que pour les personnes qui s'en servent vraiment.
4. Documentez la règle d'usage pour l'équipe.
