## axe-core et mise en page (site en ligne)

19 pages (dont les deux nouveaux outils, la 404 et une page anglaise) × 3 largeurs (1440, 768, 375 px) × 2 thèmes, soit 114 combinaisons :

- **0 violation axe** (WCAG 2.2 AA) ;
- aucun défilement horizontal ;
- un seul `h1` par page.

Les seules « petites cibles » signalées sont des champs dont la cible réelle est l'étiquette de 44 px (cases à cocher, champs fichier). La seule exception est le champ piège à robots du formulaire de contact, hors écran. WCAG 2.5.8 est respecté.

Contrat public en ligne : **75/75** (71 URL d'origine, les 4 nouvelles URL des outils, 404 réel).

## Changements livrés

| Domaine                 | Changement                                                                                                                                                                                   |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Workflow                | Push direct sur `main`, déploiement automatique après une CI verte, préproduction retirée, tag `pre-refonte`, `pnpm verify`.                                                                 |
| Design system           | Échelles de z-index, de durées et d'ombres ; composants alerte, tableau et puce (44 px) ; règle `[hidden]`.                                                                                  |
| Mise en page            | Menu mobile repliable (en-tête de ~210 px ramené à ~64 px), bandeau de consentement sans CLS, espaces manquants, en-têtes de page, cartes d'outils, filtres du blog et fil d'Ariane à 44 px. |
| Accueil                 | Hero avec accroche et trois CTA, terminal interactif, compétences par domaines, cartes des 12 outils, contact avec les deux CV.                                                              |
| Terminal                | Plus de 20 commandes, historique, complétion, accessible, désactivable, sans JavaScript dégradé proprement.                                                                                  |
| Curseur                 | Curseur façon Figma qui remplace celui du système (à votre demande), avec repli sur le curseur natif dans tous les cas sensibles.                                                            |
| Rapport SEO             | Plus de 30 contrôles avec gravité, score, recommandations, export JSON et impression.                                                                                                        |
| Vérificateur de sitemap | Découverte, fichiers, index, URL, `robots.txt`, échantillon de 20 pages.                                                                                                                     |
